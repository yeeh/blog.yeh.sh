> 新 Mac 不从旧机迁移时，用这份清单从系统设置、开发环境到常用软件依次完成。2021 年的补充已合并到这里。

## 1. 先完成系统设置

- 联网并登录 Apple ID；按需登录 Chrome。
- 关闭不需要的数据共享和 Siri 录音；设置 Finder。
- 开启三指拖移，设置输入法切换和 Launchpad 快捷键。
- 修改设备名称；在系统账号中添加 Gmail。
- 检查 Messages、FaceTime 的接收地址。
- 配置 Time Machine 备份。

## 2. 安装基础软件

优先安装并登录日常离不开的服务：1Password、Surge、Telegram 等聊天工具，以及 Office 365 等办公软件。

其余按需要补齐：Alfred（和快捷键）、Notion、WebStorm 等编辑器、图片处理工具、MoneyWiz、IINA 等影音工具和下载工具。

## 3. 配置开发与终端环境

先安装 Xcode（或至少命令行工具），再安装 Homebrew：

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

macOS 已自带 zsh；如需确认或重新设为默认 shell：

```sh
chsh -s "$(which zsh)"
echo "$SHELL"
```

安装 [iTerm2](https://iterm2.com/) 和 [Oh My Zsh](https://ohmyz.sh/)。常用补全和语法高亮插件可这样安装：

```sh
cd ~/.oh-my-zsh/custom/plugins
git clone https://github.com/zsh-users/zsh-autosuggestions.git
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git
```

在 `~/.zshrc` 中启用它们：

```sh
plugins=(git zsh-autosuggestions zsh-syntax-highlighting)
```

需要目录跳转时再安装并启用 autojump；旧的 `incr` 插件不再单独配置。

## 4. 配置 SSH

私钥放在 `~/.ssh/`，限制权限后再加入 agent：

```sh
chmod 400 ~/.ssh/xxx_rsa
ssh-add ~/.ssh/xxx_rsa
```

如有固定的工作目录或 npm alias，再写入自己的 shell 配置；不要把真实用户名、路径或私钥名称提交到配置仓库。
